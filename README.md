# JobTrack – Job Application Management System

## About the Project

JobTrack is a web-based application designed to help job seekers organize and track their job applications in one place. It provides a dashboard to monitor application statuses and recruitment progress.

## Features

- Dashboard displaying application statistics
- Add new job applications
- Edit and delete existing applications
- Search applications by company name or job title
- Filter applications by recruitment status
- Visualize application statistics using charts
- Save application records using browser LocalStorage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

## Project Structure

JobTrack/
- index.html
- style.css
- script.js
- README.md

## How to Run the Project

1. Download or clone this repository.
2. Open the JobTrack folder in Visual Studio Code.
3. Open `index.html`.
4. Run the file using the Live Server extension.
5. Use the dashboard to add and manage job applications.

An internet connection is required to load Chart.js from its CDN.

## Data Storage

Job application records are stored in the browser using LocalStorage. The data is not stored in a remote database and is specific to the browser and website origin being used.
